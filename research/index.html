What to test in Juggles

  1. Run the same routine for each counting method. Track a short session by hand, including a ground bounce and a deliberate drop. Compare the camera, microphone and ball-sensor results for missed touches, double counts and resets before using the scores for a leaderboard.
  2. Compare a kick with a bounce. The CodeCell C3 combines an ESP32-C3, Bluetooth and an inertial measurement unit. Record acceleration peaks and rotation, then test whether a piezo sensor adds a useful contact signal. A rechargeable battery and wireless coil are possible additions for an enclosed prototype. Microbots board documentation
  3. Check access to live events. Kaizen’s ball pairs with the INSAIT JOY app. Before buying it for development, ask the manufacturer about a public API or SDK for touches and drops, and about NZ fulfilment. Pairing and drill support
